# Dew Theory — Premium Skincare Storefront

A responsive React + Vite storefront concept with an editorial sage-and-ivory aesthetic, custom local SVG skincare illustrations, floating motion, reveal-on-scroll effects, category filters, wishlist hearts, a working demo shopping bag, and a newsletter confirmation.

## Run locally

1. Extract the ZIP folder.
2. Open the `dew-theory-premium` folder in VS Code.
3. Open **Terminal → New Terminal**.
4. Run these commands one at a time:

```bash
npm install
npm run dev
```

5. Open the Local URL printed in the terminal (usually `http://localhost:5173/`).

## Notes

- All product illustrations are embedded/local SVG-style artwork, so the page visuals do not depend on external image hosting.
- The cart and wishlist are front-end demo interactions. Checkout/payment processing and real order storage are not connected.
- Fonts use system fallbacks if web fonts are unavailable; internet is only needed to load the optional Google Fonts import in the stylesheet.
